# 서바이벌 게임 (타자연습 / 정보퀴즈)

35명 동시 접속 · 40종 동물 캐릭터 랜덤 배정 · 두 개의 독립된 방(타자연습 / 정보퀴즈)을 지원하는 서바이벌 게임입니다.

## 게임 규칙
1. 닉네임 입력 + 방 선택(아래 9개 중 하나) → 입장 → 40종 동물 캐릭터 중 랜덤 배정.
   1. ⌨️ 타자연습
   2. 📚 상식 퀴즈 (일반 상식)
   3. 🏫 해원고 퀴즈 (우리 학교 관련)
   4. 🧠 정보 퀴즈 (고등학교 정보 교과, **5초 고정**)
   5. 🤖 인공지능 퀴즈 (**5초 고정**)
   6. 📊 데이터과학 퀴즈 (**5초 고정**)
   7. 🔤 끝말잇기 (자유경쟁 - 아무나 먼저 이으면 인정, 사전 단어만 정답)
   8. 🔥 나락퀴즈 (한국인이라면 모르면 안 되는 상식/역사)
   9. 🈂️ 초성퀴즈 (초성 보고 단어 맞히기)
2. 대기실은 방마다 완전히 분리되어 있습니다. 각 방 첫 입장자가 호스트가 되어 "게임 시작" 가능. 대기실 좌상단 "← 처음으로" 버튼으로 언제든 나갈 수 있음.
   - **타자연습**: 대기실에서 호스트가 "English / 한글" 중 단어 언어를 선택할 수 있습니다 (다른 참가자에게도 실시간 반영, 변경은 호스트만 가능).
3. 라운드 시작 전 3-2-1 카운트다운(효과음) 후 문제 제시.
   - **타자연습**: 영어 또는 한글 단어가 그대로 화면에 보이고, 그 단어를 정확히 입력.
   - **정보 퀴즈**: 고등학교 정보 교과(컴퓨팅시스템/데이터/네트워크/알고리즘/파이썬 제어구조/디지털윤리) 문제 30개.
   - **상식 퀴즈**: 일반 상식 문제 20개.
   - 두 퀴즈 모두 순서는 매번 무작위 셔플, 문제를 다 쓰면 그 시점 순위로 게임 종료.
4. 맨 위에서 **3칸 아래** 위치에서 시작. 정답이면 위로 한 칸(그 라운드 **가장 먼저** 맞춘 사람은 1.5칸!) 이동, 오답/시간초과면 아래로 한 칸 즉시 이동 + 효과음.
5. 제한시간은 방마다 다릅니다.
   - **타자연습 / 상식 퀴즈 / 해원고 퀴즈**: 5초부터 시작해서 라운드가 진행될수록 점점 줄어듭니다 (1-10R 5초 → 11-20R 4초 → 21-26R 3초 → 27-31R 2초 → 32R~ 1초).
   - **정보 퀴즈 / 인공지능 퀴즈 / 데이터과학 퀴즈**: 라운드와 상관없이 **항상 5초 고정**입니다.
6. 맨 아래 물에 닿으면 탈락. 마지막 1명이 남으면(또는 정보퀴즈는 30문제 소진 시) 순위와 함께 결과 표시.
7. 게임 중 **호스트만** ESC로 일시정지/재개/재시작 가능. **누구나** 화면 좌상단 "🏆 순위" 버튼으로 게임을 멈추지 않고 실시간 순위 확인 가능.
8. 화면 **우측 상단 "🚪 나가기" 버튼**을 누르면 그 라운드에서 즉시 기권(탈락) 처리되고 대기실 화면으로 돌아갑니다. 방을 완전히 떠나는 건 아니라서, 그 판이 끝나면 자동으로 다음 게임 대기실로 전환됩니다. (다른 참가자들의 게임은 계속 진행됩니다)
9. 화면 **우측 하단에 작은 채팅창**이 있어 대기실/게임 중 언제든 참가자끼리 채팅 가능 (헤더 클릭하면 접고 펼 수 있음).

## 🧠 문제 / 단어 수정하기

각 방의 내용은 아래 파일 하나씩만 고치면 됩니다. 서버 코드를 건드릴 필요 없습니다.

- `words.js` — 타자연습 영어 단어
- `words-kr.js` — 타자연습 한글 단어
- `wordchain-seed-words.js` — 끝말잇기 시작 단어 후보
- `wordchain-dictionary.js` — 끝말잇기 정답으로 인정할 단어 사전
- `jungbo-quiz-questions.js` — 정보 퀴즈 문제 (고등학교 정보 교과)
- `ai-quiz-questions.js` — 인공지능 퀴즈 문제
- `datascience-quiz-questions.js` — 데이터과학 퀴즈 문제
- `common-quiz-questions.js` — 상식 퀴즈 문제 (일반 상식)
- `haewon-quiz-questions.js` — 해원고 퀴즈 문제 (우리 학교 관련)
- `narak-quiz-questions.js` — 나락퀴즈 문제
- `chosung-quiz-questions.js` — 초성퀴즈 문제

### 🔤 끝말잇기 방식 안내
- **자유경쟁 방식**입니다: 서버가 이어야 할 단어를 제시하면, 참가자 중 누구든 그 단어의 마지막 글자로 시작하는 새 단어를 가장 먼저 입력하면 인정됩니다. 그 즉시 라운드가 끝나고, 나머지 사람들은 그 라운드에서 오답(시간초과) 처리됩니다.
- **검증 규칙**: 두 글자 이상 / 한글만 / 마지막 글자로 시작 / 중복 단어 아님 / **`wordchain-dictionary.js`에 등록된 단어인지** — 이 다섯 가지를 확인합니다.
- 즉, 실제로 존재하는 단어라도 `wordchain-dictionary.js`에 없으면 오답 처리됩니다. 참가자가 "이거 진짜 단어인데요!" 하면 그 단어를 이 파일에 추가해주시면 됩니다 (지금은 1,500여 개 등록되어 있음).

퀴즈 파일 형식 예시:
```js
const QUIZ_QUESTIONS = [
  { question: "대한민국의 수도는?", answer: "서울" },
  { question: "1+1=? (숫자만)", answer: "2" },
  // ... 원하는 만큼 추가/삭제/수정 가능 (개수 제한 없음)
];
```
- `question` : 화면에 보여줄 문제
- `answer` : 참가자가 입력해야 하는 정답 (앞뒤 공백 무시, 대소문자 구분 안 함)

파일을 고친 뒤 서버를 재시작(로컬이면 `npm start` 다시, 클라우드면 재배포)하면 바로 반영됩니다.

## 실행 방법 — 클라우드 배포 (원격 참가자에게 추천)

1. 이 폴더의 파일들을 **압축 없이 그대로** GitHub 레포에 올립니다 (레포 루트에 `server.js`, `package.json`, `public/` 폴더 등이 바로 보여야 함).
2. [render.com](https://render.com) → New + → Web Service → 그 레포 연결.
3. Build Command: `npm install` / Start Command: `npm start`.
4. 배포 후 생기는 `https://프로젝트이름.onrender.com` 주소를 참가자들에게 공유.

> 무료 플랜은 오래 안 쓰면 슬립 상태가 되어 첫 접속이 느릴 수 있습니다. 게임 시작 5~10분 전에 미리 한 번 접속해 깨워두세요.

## 설정 변경

`server.js` 상단 값들:
- `MAX_PLAYERS` : 최대 동시 접속 인원 (기본 35)
- `START_ROW` : 시작 위치 (기본 3, 맨 위에서 3칸 아래)
- `MAX_ROW` : 물(최하단) 위치 (기본 10)
- `getRoundTime(round)` : 점점 줄어드는 라운드별 제한시간 규칙 (기본 5초 시작)
- `createRoom(...)` 마지막 인자(`fixedRoundTime`) : 방을 만들 때 숫자를 넣으면 그 방은 라운드와 상관없이 항상 그 초로 고정됩니다 (지금은 정보/인공지능/데이터과학 방에 `5`로 지정되어 있음). 빼면 `getRoundTime` 규칙을 따릅니다.

타자연습 단어 목록은 `words.js`, 캐릭터 목록은 `animals.js`, 퀴즈 문제는 `jungbo-quiz-questions.js`에서 수정합니다.
